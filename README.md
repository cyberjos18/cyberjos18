## Jose Angarita

**Tech lead and software engineer.** Twelve years with PHP, six of them building Laravel platforms, and four leading agile teams of two to six people across web, mobile and desktop stacks.

Most of my work has been on systems where a mistake carries a real cost: hospital equipment that has to be repaired, families that have to be found again. That shapes how I build — layered architecture, access rules enforced per role, and test suites that run against a real database instead of a convenient mock.

### Selected work

**[juntos-de-nuevo-family-reunification-platform](https://github.com/cyberjos18/juntos-de-nuevo-family-reunification-platform)**
A humanitarian platform for reuniting children with their families after an emergency. Shelters register the minors in their care, relatives find them publicly, and the pickup is recorded with photographic evidence as an irreversible state change. In production at [juntosdenuevo.org](https://juntosdenuevo.org).
*Laravel 13 · PHP 8.3 · MySQL 8 · Blade · Tailwind CSS 4 · Pest · GitHub Actions*

**[medtech-incident-manager](https://github.com/cyberjos18/medtech-incident-manager)**
Incident management for medical equipment across the hospitals of a public health network.
*PHP · Blade · JavaScript*
